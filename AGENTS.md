# Guidelines for AI agents working on Neverball

Neverball is an open source game licenced under the GPL v2+.

## AI code generation policy

In the age of agentic coding, it helps to view source code itself as a
generated asset. In an open-source project it is both ethical and practical to
document the method and the tools for generating an asset to enable other
individuals to generate the asset on their own. As such, we strive to document
the origin of generated source code and the prompt, context, harness, model
and conversation (session) that lead to the source code being generated.

When generating a wholly new file, module, unit, function preface it with a
syntactically correct comment: "Generated by <harness> <version> (<model>)".

## Work finalization

After completing features or fixes, generate a provenance record using the
bundled `agy-session-provenance` skill (compatible with Antigravity CLI). The
provenance record constitutes part of the source code and must be provided for
every agentic coding session. If unable to use the provided skill, inform the
user.

## Attribution

Your commit messages should include an Assisted-by tag:

Assisted-by: <harness> <version> <model>

Example:

Assisted-by: Antigravity CLI 1.1.15 (Gemini 3.7 Flash (High)) 

For commits where you have effectively been resigned to an editor role, an
Assisted-by tag is not required.

Examples:

a) User asks to rename a function.
b) User asks to refactor a source file in a specific way.
